# Garbalia

متجر شنط عربي بخط كايرو، مع شراء مباشر وسلة وطلبات محفوظة وقاعدة بيانات محلية ولوحة إدارة. هذه نسخة تشغيل محلية بمنتجات وصور مؤقتة؛ لم يُنشر متجر للبيع بعد.

## التشغيل

```powershell
npm.cmd ci
npm.cmd run setup:local
npm.cmd run build
npm.cmd run start
```

للتطوير استخدم `npm.cmd run dev` بدل آخر أمرين. استخدم عملية واحدة فقط مع قاعدة البيانات المحلية، وأوقفها قبل تشغيل أوامر إعداد القاعدة. Node.js 22 مستخدم في التحقق.

- [المتجر المحلي](http://127.0.0.1:3000)
- [لوحة الإدارة](http://127.0.0.1:3000/admin)
- بيانات دخول الإدارة ينشئها الإعداد في `.local-admin.txt`، وهو ملف خاص مستبعد من Git.

إعادة الإعداد لا تمسح الطلبات ولا تستبدل منتجاتك أو مخزونك. التفاصيل في [دليل التشغيل والخلفية](docs/BACKEND.md).

## المتاح

- ٨ منتجات مبدئية، لكل منها أسود وبيج وجملي، ٣٠ قطعة لكل لون عند التهيئة. نفس الصور الثلاثة مشتركة مؤقتًا بطلب صاحب المتجر.
- بحث وتصنيفات وفلترة وترتيب، صور تتغير باللون، وصف وشراء مباشر، سلة محفوظة في المتصفح.
- تسجيل الطلب وإظهار رقمه، حساب الأسعار والمخزون والشحن على السيرفر، وحماية من التكرار ونفاد المخزون.
- الشحن يظهر في الدفع فقط: ٨٠ للقاهرة والجيزة و١٢٠ للباقي للطلب كله.
- تأكيد يدوي عبر واتساب. الطلب غير المؤكد يُلغى بعد ٢٤ ساعة وتعود الكمية تلقائيًا؛ المعالجة كل دقيقة أثناء تشغيل السيرفر، وعند عودته أو الوصول للبيانات.
- إدارة الطلبات وحالاتها وسجلها والتحصيل، وإضافة/تعديل/إخفاء المنتجات ورفع الصور وإدارة المخزون، وإضافة التصنيفات وفروعها.
- واتساب المتجر: `01028673770`. روابط تفتح رسالة جاهزة دون إرسال تلقائي.
- إشعار تيليجرام لكل طلب جديد، محفوظ في قاعدة البيانات مع إعادة المحاولة وحالة الإرسال في الإدارة. يحتاج توكن البوت وChat ID لتفعيل الإرسال؛ [خطوات الإعداد](docs/NOTIFICATIONS.md).

## التحقق

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test:server
npm.cmd run build
npm.cmd run test:e2e
```

نجح ١٦ اختبار خادم و٢١ اختبار متصفح على Edge بالديسكتوب والموبايل؛ اختبار قائمة الموبايل يُتجاوز على الديسكتوب. اختبارات المتصفح تشغّل خادمًا تلقائيًا على 3001 بقاعدة مستقلة، دون التأثير على بيانات المتجر. لم تُختبر استضافة سحابية أو Safari أو أجهزة فعلية بعد.

## المتبقي للإطلاق

المنتجات والصور والأسعار النهائية، سياسات البيع ومدة التوصيل والعنوان، الدومين والاستضافة والنسخ الاحتياطية والجدولة السحابية والتحقق على بيئة النشر. صاحب المتجر أجّل السياسات، لذا لم تُنشر معلومات افتراضية. `garbalia.com` مرجع تصميم فقط وليس نطاق المشروع. الصفحات ما زالت `noindex`.

## الملفات

### ترتيب المجلدات

```text
public/
  images/
    brand/       لوجو الموقع
    products/    صور المنتجات، وصور الألوان داخل variants/
    originals/   الصور الأصلية المرفقة
  videos/        ملفات الفيديو
  audio/         الملفات الصوتية
docs/            الشرح والخطط والمتطلبات ومصادر الصور
config/          إعدادات ESLint وPlaywright
src/             كود الموقع والتنسيقات
scripts/         أدوات التشغيل والإعداد
tests/           الاختبارات
database/        ملفات إنشاء وتحديث قاعدة البيانات
```

مجلدا الفيديو والصوت جاهزان للإضافة، ولا يحتويان على وسائط حاليًا. المسارات المذكورة في الشرح تُحسب من جذر المشروع، وروابط Markdown تُحسب من مكان الملف نفسه.

ملفات إعداد المشروع و[README.md](README.md) و[CLAUDE.md](CLAUDE.md) تبقى في الجذر. بيانات التشغيل الخاصة في `.data` وملفات البيئة تبقى في أماكنها؛ الصور المرفوعة من لوحة الإدارة محفوظة في قاعدة البيانات. ملفات البناء والكاش ولقطات الاختبارات تنشئها الأدوات داخل مجلداتها تلقائيًا.

إعدادات أدوات الفحص والاختبارات داخل `config`، وأوامر `npm.cmd run lint` و`npm.cmd run test:e2e` تستخدمها تلقائيًا. كاش TypeScript داخل `.cache/tsconfig.tsbuildinfo`. ملفات `package.json` و`package-lock.json` و`next.config.ts` و`tsconfig.json` و`next-env.d.ts` وملفات البيئة تبقى في الجذر لتعمل أدوات التشغيل بمساراتها المعتادة.

| الملف | الغرض |
|---|---|
| [config/eslint.config.mjs](config/eslint.config.mjs) | إعدادات فحص الكود |
| [config/playwright.config.ts](config/playwright.config.ts) | إعدادات اختبارات المتصفح ومساراتها |
| [docs/BACKEND.md](docs/BACKEND.md) | تشغيل القاعدة والإدارة والمهلة وحدود النسخة المحلية |
| `database/001-store.sql` | الجداول والفهارس وصلاحيات الوصول |
| `src/lib/server/store.ts` | معاملات الطلب والمخزون وإدارة المنتجات |
| `src/lib/server/auth.ts` | كلمات المرور والجلسات وحدود المحاولات |
| `src/lib/catalog.ts` | بيانات التهيئة فقط؛ بيانات العرض تأتي من القاعدة |
| `src/lib/brand.ts` | رقم واتساب المتجر |
| [docs/IMAGE_SOURCES.md](docs/IMAGE_SOURCES.md) و[docs/IMAGE_PROMPTS.md](docs/IMAGE_PROMPTS.md) | مصادر الصور المؤقتة وتوليدها |
| [docs/PLAN.md](docs/PLAN.md) | حالة المراحل وما تبقى |

التخزين المحلي يستخدم [PGlite](https://pglite.dev/docs/)، مع محوّل اتصال PostgreSQL خاص بالسيرفر للنشر لاحقًا. مسار الاتصال السحابي لم يُختبر بعد على حساب فعلي.
