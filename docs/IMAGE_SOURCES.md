# Garbalia — صور التخطيط والعرض المبدئي

تاريخ البحث والتنزيل: ٢٠ سبتمبر ٢٠٢٦. تحديث ٢١ سبتمبر: صور بطاقات المنتجات الحالية هي ٣ صور مؤقتة مولدة عبر أداة imagegen المدمجة، مشتركة بين الموديلات بطلب صاحب المتجر. الملفات والأوامر في [docs/IMAGE_PROMPTS.md](IMAGE_PROMPTS.md). الصور المرجعية الأصلية أدناه توثيق للمصدر؛ صور الألوان ليست تصويراً لمخزون حقيقي.

تم تنزيل ٨ صور محلياً وفحصها بصرياً. هذه مجموعة مرجعية للتصميم، وليست كتالوجاً موثقاً لمنتجات Garbalia. الأرقام لتعريف ملفات الصور فقط، وليست أسماء موديلات نهائية. لا توفر المجموعة صوراً مطابقة للألوان الثلاثة لكل منتج.

المصدر: Pexels. [شروط استخدام الصور](https://www.pexels.com/license/) تسمح بالتنزيل والاستخدام المجاني، ولا تسمح بالإيحاء بتأييد أشخاص أو علامات ظاهرة في الصور للمنتج. الصور 04 و05 و06 بها علامات تجارية ظاهرة؛ تستخدم للمراجعة الداخلية فقط وتُستبدل قبل العرض العام باسم Garbalia.
